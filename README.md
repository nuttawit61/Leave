# ระบบบันทึกการลา — ภาควิชาเวชศาสตร์การธนาคารเลือด

ระบบบันทึกและติดตามการลาของบุคลากร พัฒนาเป็น Static Web App (HTML + JavaScript ล้วน) ไม่ต้องติดตั้ง server

## คุณสมบัติ

- บันทึกการลาหลายประเภท: ลาป่วย, ลาพักผ่อน, ลากิจ, ลาประชุม, **ลาเป็นวิทยากร**, ลาคลอด, ลาบวช, ลาอื่นๆ
- ปฏิทินแสดงการลารายเดือน
- รายงานประจำวัน พร้อม copy ข้อความสำหรับ LINE
- Export ข้อมูลเป็น CSV และ Excel (.xlsx)
- เพิ่มเข้า Google Calendar ได้โดยตรง
- บันทึกข้อมูลใน localStorage (ไม่ต้องใช้ backend)
- รองรับการแนบ URL E-DOC

## ไฟล์

| ไฟล์ | คำอธิบาย |
|------|----------|
| `index.html` | หน้าหลัก (Dashboard / ภาพรวม) |
| `leave.html` | ระบบบันทึกการลา (ฟอร์ม + ปฏิทิน + รายงาน) |
| `logo-ภาควิชา_แนวตั้ง2_0.png` | โลโก้ภาควิชา |

## วิธีใช้งาน

เปิดไฟล์ `leave.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่มเติม

หรือ deploy ขึ้น **GitHub Pages**:
1. Push ไฟล์ทั้งหมดขึ้น repository
2. ไปที่ Settings → Pages → Source: `main` branch, root folder
3. เปิดใช้งานผ่าน `https://<username>.github.io/<repo>/leave.html`
